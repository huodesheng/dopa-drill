# 噜噜练习 — 公开版规格书

噜噜练习是一款浏览器游戏：每做完一道计算，吉祥物的动作、画面演出和音乐就再热闹一档。本文面向玩家、家长，以及想开发和改造的人，说明当前实现的行为。数值以后可能会调整。

## 1. 概要和设计思路

目标是每天做一点计算，并能对照过去的自己看到进步。基础题即使超时也可以继续做，全部做完就是 100 分。没有游戏结束。

答错显示「差一点」，可以重做。已经拿到的星星、奖杯和演出，不会因为失败或缺席被收回。连续记录有补缺席的办法，成长对比只显示变好的项目。奖励按条件解锁，没有抽奖，也没有付费获取。

界面是中文，面向小学生计算练习，大人也可以用。以手机竖屏为主，电脑的鼠标和键盘也能操作。不需要注册账号。记录按浏览器分开保存，不同设备之间不会自动同步。

## 2. 画面和流程

### 2.1 画面一览

| 画面 | 内容和主要操作 |
| --- | --- |
| 标题 | 标志、噜噜、我的等级、紧挨着的复习、1–6 年级、技能树、奖杯、收藏、任务、日历、设置、？ |
| 练习 | 题目、输入格、专用数字键盘、正确数、差一点的次数、时钟、噜噜、连击、进度、静音 |
| 基础结果 | 100 分、用时、一次做对率、噜噜、成长·技能·任务的结果。达标时可进加试，以及重做、再玩、回标题 |
| 最终结果 | 含加试的得分和噜噜、正确数、差一点的次数、任务，以及重做、回标题 |
| 技能树 | 前提关系、解锁·练习·掌握状态、星星、生锈、技能说明和练习、部分删除记录 |
| 奖杯 | 按分类和系列的成就、获得日期、条件和奖励、筛选、快要获得的成就 |
| 收藏 | 已解锁演出的试看和试听，每个类别可以固定或随机 |
| 设置 | 题数、声音、音量、动画强度、演示、全部数据重置 |

通常流程是「标题 → 基础题 → 基础结果 → 可选的加试 → 最终结果」。复习只到基础结果。结果画面的操作按钮固定在下端，成长记录变多也不会挡住下一步。

### 2.2 初次引导和「？」帮助

第一次会显示 5 页引导。顺序是导入、我的等级、按年级、技能树、推荐使用我的等级。设置按钮下面的「？」可以再看一遍，并加上奖杯和收藏，共 7 页。

说明对象用聚光灯照亮，必要时会滚动。说明文字放在独立卡片里，噜噜用移动、指点和表情来引导，不会把说明当成它的台词。最后指出「我的等级」和「？」，如果两者不能同时放进画面，卡片里会显示同样的问号图标。

用「下一步」「返回」「跳过」操作，最后一页是「开始！」。回车和右箭头是下一步，左箭头是上一步，Escape 是跳过，Tab 在引导内移动焦点。点暗幕不会关闭，引导中也不能操作背景按钮。

看完和跳过都会记成已看过。初次引导之后，按补签锤子、登录奖励、奖杯通知的顺序处理。全部重置后会再次显示初次引导。演示中和一部分确认用 URL 不会自动弹出。

## 3. 模式

### 3.1 我的等级

第一次是「实力检测」。技能按年级、前提深度排序后往前走。一次做对，就把这道题对应的技能和它的前提一起标成掌握、☆1。步长一开始是 6，做对后把当前步长乘 1.3 再向上取整，最大 12；答错后减半再向下取整，最小 1。答错后会回到最后一次做对的位置之后。基础题做完，就算检测完成。

之后的出题按前提深度、年级、技能定义顺序来选。从已掌握的末尾 6 个技能里挑复习，复习题数是 `min(候选数, max(1, round(题数 × 0.3)))`。生锈的技能优先，其余从候选里随机选。没有已掌握的技能时，复习题数是 0。

剩下的题，从已解锁、未掌握的前 4 个技能里按顺序重复。全部掌握后，就从全部已掌握技能里选。加试重复未掌握候选的末尾 3 个技能；没有的话，重复已掌握的末尾 3 个。检测刚结束的加试，从已解锁、未掌握的开头选。

### 3.2 按年级

不管解锁状态，从所选年级的技能出基础题。从前提浅的排到深的，再加一点随机抖动。答题结果照常计入掌握度。

加试的前 6 题，重复该年级技能列里 `floor(技能数 × 0.55)` 之后的部分。从第 7 题起切换到下一年级的前 4 个技能。6 年级继续用同一年级的后半段。

### 3.3 练习

从技能树选择已解锁的技能来练习。已掌握的技能可以从说明画面开始练习。基础题就是这个技能，加试从这个技能直接作为前提、且已解锁的技能里选。没有对象就继续同一个技能。

按年级和练习里，满足条件的时间胶囊可能替换基础题中的 1 题。这一题可以超出指定的年级和技能范围。

### 3.4 复习

含有答错的题目，在做完的那一刻把题目本身存下来，最多 40 题。用标题和式子做标识来去重。中途中断、没做完的题不会加入。

可以从标题和结果里的重做按钮开始。从已保存列表的末尾，取设置题数和 10 中较小的那个作为上限。从结果按钮开始，也不只限这一局的错题，而是用以前留下来的列表。

一次做对的题会从列表删除，再次答错的题会留下。全部做完就是 100 分，没有加试。照常计入成长记录、掌握度和任务。

### 3.5 演示

设置里的「自动演示」会开始自动操作。从全部技能里选容易的题目排序，加试从 4 年级以上的技能里选。用正常的输入、判定和演出，也会故意答错。基础题答错的题数上限是 `floor(题数 × 0.2)`。

基础、加试、最终结果走完一圈就回标题，并解除演示。点一下或按键也会结束。开始后 600 毫秒内的点击会被忽略。演示结果不计入历史、掌握度、复习和成长统计，也不推进任务和奖杯。回到标题后会做通常的登录处理。

固定的演出在演示里也会用，只有设成随机的类别才从已解锁的里面选。URL 的 `?demo` 是另一个功能，不是这个自动操作。

## 4. 一局练习和输入

### 4.1 基础题和加试

题数是 6、10、14，默认 10。基础题目标时间是 `ceil(题数 × 18 ÷ 10) × 10` 秒：6 题 110 秒，10 题 180 秒，14 题 260 秒。超时也可以继续，不扣分。基础题用时从开始做到全部做完，包括切题的时间。

「正确」是做到最后一步的题数，「差一点」是输入的数字和当前格子不符的次数。「一次做对」是包括中间步骤在内一次都没错地做完。基础题一次做对数除以题数达到 0.8 以上，就可以选加试。

加试默认 90 秒。开始处理的时刻加上 90,000 毫秒和导入用的 900 毫秒，作为截止时间。不是从第一次可以输入的时刻起保证 90 秒，切题时时钟也在走。确认对话框期间会暂停。时间到就确定得分，进入最终结果。没做完的题不得分，但已经判对的格子增加的噜噜会留下。

### 4.2 数字输入

用专用数字键盘和电脑数字键一位一位输入，当场判定。没有确认按钮。正确的位数会保留，错误的数字下一次输入时替换。退格只删当前错误的数字，不撤销已经做对的位数。

手机上会按包含浏览器操作栏的显示区域，调整题目边距和键盘高度。把含 0 和删除的最下一排放在底部安全区之上，画面尺寸变化时也会重算题目字号。

| 题目形式 | 输入顺序和自动显示 |
| --- | --- |
| 横式 | 从答案左边的位数开始输入 |
| 横式有余数的除法 | 先商，后余数 |
| 加减竖式 | 从最低位开始。进位、退位的辅助数字自动显示 |
| 乘法竖式 | 部分积从右边输入，有多个部分积时合计也从右边输入 |
| 除法竖式 | 先商的高位，再减去后的余数，再下一个商。积、落下来的数字、最后的余数 0 自动显示 |
| 小数 | 小数点自动显示，只输入数字 |
| 分数 | 先分母，后分子。带分数是整数部分、分母、分子 |
| 比、含字母的式子、近似数、百分数 | 从指定空格的左边开始输入 |

分数按准备好的答案形式判定。3 年级同分母分数保留原来的分母，接受不约分的答案。其他分数计算使用生成出来的既约分数或带分数。不能自由输入等价的另一种写法来判定。

### 4.3 答错和提示

错误的数字用紫色虚线框。同一格答错 2 次，如果定义了该看的数字，就高亮并指过去。第 3 次起显示中间式或口诀列等提示。提示有时会包含相当于答案的值。

答错连击归零，但不减分、不减少噜噜，演出阶段和背景音乐保持。为了答错音会暂时压低背景音乐，并用弹跳音效和噜噜恢复的动作。

## 5. 得分、噜噜、连击

### 5.1 得分

基础题做完是 100 分。加试完成的题从 0 开始记为 `k`，这一题加 `10 + 5 × k` 分。加试完成 `n` 题的总分是：

```text
100 + 10 × n + 5 × n × (n − 1) ÷ 2
```

5 题 200 分，10 题 425 分，15 题 775 分，23 题 1595 分，30 题 2575 分。得分没有固定上限。连击、答题速度、差一点的次数都不乘分，也不扣分。

### 5.2 噜噜的计算

噜噜是演出用的数值，和得分分开。内部值 `L` 是常用对数，显示值的来源是 `10^L`。一局开始时 `L = 0`。

基础题基准曲线是 `B(f) = 2.3 × clamp(f, 0, 1)^1.15`，加试基准曲线是 `X(n) = 2.3 + 3.0 × (1 − exp(−n / 10))`。

基础题总数为 `N`，已完成题数为从 0 开始的 `q`，当前题的答题格数为 `m`，这次做对的格子为从 1 开始的 `s`，这次输入的基准增量是 `B((q + s/m)/N) − B((q + (s−1)/m)/N)`。加试已完成题数为 `k` 时，一格的基准增量是 `(X(k+1) − X(k))/m`。

做对时先把连击数 `c` 加 1，再用下式反映这次输入：

```text
倍率 M(c) = 1 + (2 − 1) × min(1, max(0, c) / 20)
新的 L = min(9.08, L + max(0.003, 基准增量) × M(c))
```

10 连击是 1.5 倍，20 连击以上是 2 倍。上限是对数值 9.08，对应显示值正好是 `10^9.08`。增量有最低值 0.003，所以不能只凭基准曲线的终点决定实际到达值。第一次做对也是 1 连击、1.05 倍。加试开始时连击归零，噜噜继续累计。

显示上，不到 1 万取整，之后加上「万」「亿」等。单位内的值小于 10 时保留一位小数，10 以上向下取整。到达 100、1000、1 万、10 万、100 万、1000 万、1 亿时有节点演出。正常玩法的上限到不了兆以上。

### 5.3 连击时间和显示

每个做对的答题格加 1 连击，跨题保留。2 连击以上才显示，20 连击以上显示「噜噜×2 MAX」。答错或时间到归零。不过当前实现里，1 连击的状态不参与时间到的判定。

年级 `g` 的普通格子时间是 `3000 + 600 × (g − 1)` 毫秒，题目的第一格再加 2500 毫秒。年级收在 1–6，不明时按 3 处理。

| 年级 | 普通格子 | 题目的第一格 |
| --- | --- | --- |
| 1 | 3000ms | 5500ms |
| 2 | 3600ms | 6100ms |
| 3 | 4200ms | 6700ms |
| 4 | 4800ms | 7300ms |
| 5 | 5400ms | 7900ms |
| 6 | 6000ms | 8500ms |

在可以接受输入的时刻设定截止时间，切题和确认对话框不消耗它。剩余时间条低于 30% 时会强调。10、20、30、50、75 连击，以及 100 以上每 50 连击，会大大庆祝一次。5 连击以上中断时，会短暂显示结束时的连击数。

## 6. 出题范围和技能树

### 6.1 范围和生成

计算分成 58 个技能。按年级是 1 年级 8 个、2 年级 13 个、3 年级 14 个、4 年级 10 个、5 年级 8 个、6 年级 5 个。系列是「加减」「乘除」「小数·分数」「其他」四种。全部技能的名字、标识、前提和生成条件汇总在 `docs/curriculum.md`。

包括四则运算、带中间输入的竖式、小数、分数、近似数、公约数和倍数、运算顺序、百分数、相等的比、字母的值。不出图形、测量、图表、应用题和汉字数字。

每次按技能条件用随机数生成。用最近 24 题的签名和这一局已出题的签名来避免重复。候选生成有重试上限，候选少的技能仍可能重复。时间胶囊和复习是为了复现同一道题的例外。

### 6.2 显示和解锁

每个系列分成两列，共 8 列。窄屏幕可以纵横滚动。按年级优先排列，5、6 年级放在 1–4 年级下面。前提关系的线会绕开其他节点，同一列上下相邻并不表示有依赖。

没有前提的技能一开始就解锁，有多个前提时必须全部掌握。状态区分锁定、新的、练习中、已掌握。通常的掌握条件是至少有 6 题历史，最近 6 题里至少 5 题一次做对。一旦掌握，答错也不会退回。实力检测的一次性授予是这个次数条件的例外。

### 6.3 技能的星星

掌握后按顺序获得☆1 到☆5。必须一档一档满足条件，同一次判定如果都满足，可以连升多档。合计最多 290。

速度判定用每题答题时间除以基准时间的比值。基准时间是 `第一格的连击时间 + max(0, 答题格数 − 1) × 普通格子的连击时间`。只从一次做对的题目里取比值的中位数。

| 星 | 条件 |
| --- | --- |
| ☆1 | 已掌握 |
| ☆2 | 最近 20 题齐了，一次做对率 0.9 以上 |
| ☆3 | 最近 10 题齐了，其中至少 5 题一次做对，时间比值中位数不超过 1 |
| ☆4 | 最近 3 题全部一次做对，每题日期都在获得☆3 之后至少 7 天 |
| ☆5 | 最近 20 题齐了，一次做对率 0.95 以上，时间比值中位数不超过 0.6 |

☆4 的 3 题不必同一天。星星不会因为正常游玩或休息减少，删除技能记录和全部重置时会消失。说明画面显示下一颗星的条件、当前值、做过的题数、最短答题时间。

### 6.4 生锈

已掌握、且距离最后一次一次做对超过 `21 × 86400000` 毫秒的技能成为候选，按从旧到新最多显示 3 个「锈」。没有一次做对的时间时，依次用实力检测授予时间和掌握时间。

生锈的技能一次做对 1 题就会被擦亮，星星保留，标记消失。擦亮之后，另一个更旧的技能可能会变成显示对象。用于我的等级的复习，以及打磨任务。

### 6.5 删除技能记录

有记录的技能长按 600 毫秒，或聚焦后按 Delete，会打开确认。从按下位置移动超过 10 像素，长按就会取消。

确定后，删除这个技能以及直接、间接依赖它的技能的记录和星星。所选技能如果前提还在，就回到新的；前提不齐，就回到锁定。历史、复习、累计统计、奖杯、收藏、实力检测完成的状态会保留。

## 7. 让人继续玩下去的机制

### 7.1 历史、日历、登录奖励

基础结果时保存历史，加试结束后更新同一条历史的得分、加试正确数、差一点和噜噜。最多保留 3000 条。日历显示每天的最高分和游玩次数，点日期可以看详情。可以回到过去的月份，不能进入未来的月份。

连续天数从今天起算；今天还没玩，就从昨天起算。也会显示最长记录和登录贴纸张数。游玩日和登录日是分开的，只打开标题不算玩过。

登录奖励按设备日期每天 1 次。按星星、爱心、花、音符、三叶草、花丸、王冠的 7 天周期领取贴纸。中间夹了没有补签的缺席日，周期就从头数。打开显示的那一刻贴纸就算领到了，关掉或重新加载，同一天也不会重复领。

### 7.2 补签锤子

1 把锤子可以把没玩的 1 天标成补签，把游玩和登录的连续接上。不会把那天算进游玩天数，也不会补发休息日的贴纸。初始持有 1 把，上限 3 把。

最后一次游玩在最近 7 天内，到昨天为止的空档能用持有数全部补上，并且能保住 2 天以上的连续时，标题页每天提议使用 1 次。拒绝的那天不再提议。使用后会在日历上盖补签章。使用历史最多 50 条。

### 7.3 每日任务

根据设备日期和当天选择时的记录，定下 2 个简单的和 1 个费事的，然后保存。同一天即使改设置也不会重选。日期变化后的更新处理会换成新列表。候选是固定的 11 种，再加上根据生锈情况出现的 1 种。

| 档 | 候选和达成条件 |
| --- | --- |
| 简单 | 做完 1 次、5 连击、一次做对 5 题、复习 1 题、新技能 1 题 |
| 费事 | 进入加试、加试 5 题、20 连击、做完 2 次、按年级做完 1 次、新的或练习中的技能 10 题、指定技能一次做对 3 题 |

没有复习或新技能对象时，就去掉对应候选。加试相关要求最近 5 条历史里有加试记录，20 连击要求 `题数 × 平均答题格数 >= 26`，练习中 10 题要求已完成实力检测且有未掌握候选。同一天不叠相同指标的任务。

用时筛选模型把 1 次算成 `(题数 × 18 + 预计会进加试时的 90 + 30) / 60` 分钟。一次做对 5 题按 `ceil(5 / (题数 × 0.7))` 次，练习中 10 题按 `ceil(10 / (题数 × 0.6))` 次，20 连击按 2 次估算。复习按最多 10 题计算，把各模式都能达成的项目叠在一起，选合计 15 分钟以内的组合。这只是估算，不限制实际用时。

打磨候选：有生锈、日期派生的随机数小于 0.5、最近 7 天提示次数少于 2 时，才会进入选择。可以从标题开始练习对应技能，达成需要同一技能一次做对 3 题。这和擦掉生锈本身的 1 题条件不同。

进度在游玩中累加，达成时在画面上端提示。复习也计入共同的做完、一次做对、连击条件。3 个全部达成，当天只领 1 次、1 把锤子，并在日历上做标记。已经到持有上限就只有演出，奖励不会留到以后。

### 7.5 和上次比较

基础结果里，同一技能比以前的记录有进步的地方，最多显示 3 行「进步了！」。这次和比较对象两边都至少要有 3 题。比较对象是上次玩的那天、21 天以前最近的那天、最初做的 3 题。不拿同一天里更早的那一局当比较对象。

答题时间按每格平均来比，显示时换算成这次平均格数下的每题秒数。时间缩短 10% 以上，或一次做对率提高 10 个百分点以上，才成为候选。每个技能选最大的一项进步，整体按进步大小排序显示。没有进步就不显示。实力检测、演示、以及停止成长记录的确认用 URL 不在范围内。

### 7.6 时间胶囊

从每个技能保存的最初 3 题里，选已掌握、解题时刻起经过 `30 × 86400000` 毫秒以上、还没用过的题中最旧的一题。

普通的我的等级、按年级、练习的基础组在 4 题以上时，替换从 0 开始的第 `max(1, min(N−2, floor(N/2)))` 题。实力检测、复习、加试、演示、停止成长记录的确认用 URL 不在范围内。每天最多 1 题，预告结束时的日期会保存，之后即使中断，当天也不会再提示。题目做完时标成已使用。

用信封预告和橙色边框，让人看得出是过去的题目。比较时，这次时间不到过去的 0.95 倍就显示时间缩短；否则看答错次数是否减少；都没有，就显示又做出来了，并显示日期。正好缩短 5% 不算时间缩短。

## 8. 噜噜、演出和声音

噜噜原则上不说话。造型基准是 `docs/dopakichi.svg`。大横耳、横向很宽的圆头、奶油色的脸和肚子、双层圆眼睛、细胳膊和蓝脚。基本色是粉色 `#FF97BF`、奶油色 `#FFF3E4`、耳朵内侧 `#FFE6F0`、蓝色 `#2F79F7`、轮廓 `#000000`。

输入的数字用空着的手搬过去。左右手可以各搬一个数字，判定和搬运分开，不等待下一次输入。中途做对和最终做对会用跳跃、拍手、旋转等，答错会倒下再起来。答错动作有 10 种，前期用 4 种，中期用 8 种，强度 0.6 以上从 10 种里选，并避开刚刚用过的。

基础题题号从 0 开始记为 `i`，题数为 `N`，演出强度是 `E = 0.08 + 0.92 × (i/(N−1))^1.3`。只有 1 题时 `E = 1`。加试对完成数 `k` 取 `tier = floor(k/3)`，`E = 1 + min(0.5, tier × 0.1)`。

强度升高时，会叠上背景、花丸等正确标记、纸屑、星星、烟花、硬币、观众、游行、冲刺、灯饰和晃动。终场从巨大噜噜、烟花大会、火箭、游行里选，最后显示 100 分。输入和数字键盘的位置、竖式的数位对应保持不变。

音乐和音效用 Web Audio API 合成，不读取外部录音素材。在基本的木琴进行曲之外，还有 8 位机、祭典鼓乐、铜管乐队、电子，共 5 首。用振荡器、噪声、滤波器和混响等，逐步叠上打击乐、低音、和弦和旋律。

基础节奏是 `112 + min(1, E) × 16` BPM，通常开头是 113.28 BPM，结尾是 128 BPM。最后一题从基准升高 2 个半音。加试是 `134 + tier × 5` BPM，调从基准升高 `2 + min(tier, 5)` 个半音。转调有上限，节奏没有这个公式以外的固定上限。

按键、数字落地、做对、答错、噜噜节点、时钟等都会用声音补充，音高和曲子的和弦同步。声音开始需要浏览器要求的用户操作。背景用 WebGL，不可用或上下文丢失时切换到 CSS 背景。

## 9. 设置和无障碍

| 设置 | 内容和初始值 |
| --- | --- |
| 题数 | 6、10、14 题。初始 10 题 |
| 声音 | 开／关。初始开。练习画面的静音也可以改 |
| 音量 | 0–100%。初始 80% |
| 动画强度 | 0–100%。未设置时，如果系统要求减少动画就是 0%，否则 100% |
| 演示 | 自动操作走一圈 |
| 全部重置 | 确认两次，初始化设备内的数据 |

动画强度会反映到粒子量、晃动、闪光、背景、观众和噜噜的大动作。0% 时停止主要的移动、晃动和闪光，引导也用静止姿势。但不是停止全部绘制，普通画面的呼吸和少量粒子仍会留下。拖动数值时可以在设置画面试反应。计算判定和得分规则不变。

Escape 会关闭打开的对话框；不在标题时，会打开「回到标题？」的确认。「继续」是初始焦点。确认期间停止输入、基础题用时、加试和连击的截止时间、每题计时。中断前已经做完的题，掌握度等会留下。基础结果之前中断，不会生成完成历史。演示中的 Escape 是结束演示。

准备了按钮的无障碍名称、焦点显示、数字以外的标签，以及引导内的焦点循环。不保证只用屏幕阅读器就能完整游玩，也不保证所有设备上的操作感。

高度 700 像素以下会调整题目纸、演出区域和边距，把数字键盘最下一行收进画面。矮屏幕也保持按键高度 48 像素。

全部重置第一次用「全部重置」说明要删的内容，第二次用「真的要删除吗？」确认无法恢复。两次都以「取消」为初始焦点。取消、Escape、点背景都不会删除。第二次确定后，删除所有前缀为 `dopa-drill` 的保存键，丢掉内存缓存并重新加载。无关的键会保留。

设置、历史、掌握度、星星、成长记录、奖杯、收藏选择、贴纸、任务、道具、初次引导状态都在初始化范围内。重新启动时，初次引导和初始道具等会重新生成。浏览器拒绝删除时，处理也不会异常结束，但不能保证已保存的数据被清掉。

## 10. 保存和隐私

保存在浏览器的 localStorage，键是 `dopa-drill:v1`，数据版本是 1。没有输入姓名等个人信息的栏，应用也不会把学习记录发送到服务器。没有广告、外部分析、排行榜和设备间同步。从分发服务器取得游戏的静态文件后运行。

保存区域不可用、读取失败或 JSON 损坏时，会以初始状态启动；即使保存失败，当场的游戏也会继续。清除浏览器数据、存储限制、换浏览器或换分发来源时，记录无法继承。

| 记录 | 内容·上限 |
| --- | --- |
| 设置·引导 | 题数、声音、音量、动画、引导已看过 |
| 完成历史 | 最多 3000 条。日期、模式、得分、正确、差一点、基础用时、噜噜、加试 |
| 技能 | 最近 6 题是否一次做对、最近 24 个签名、最近 30 题的时间·格数·答错·日期、最近 60 天的汇总、最初 3 题本身、最后一次一次做对和掌握时间、星星 |
| 复习 | 最多 40 道题本身 |
| 累计统计 | 完成题·格·一次做对·答错、基础完成和模式、基础用时、最大噜噜、加试、最大连击、复习、玩过的天数、擦亮次数、比较·胶囊 |
| 持续·奖励 | 贴纸、登录日、补签日、锤子、任务、已获得奖杯、演出选择 |

一题的答题时间是从可以输入到最后一次正确输入，不含题与题之间的演出和确认对话框。累计的题数、格数、答错在题目完成时才加，中途结束、没做完的操作不计入。

还没有统计的旧存档，会用历史里能取到的值初始化。过去的格数、最大连击等历史里没有的值，从 0 开始计。确认用 URL 不是停止全部保存的功能。具体差异见下一章。

### 11.3 确认用 URL 参数

像 `/app/?count=6&seed=123` 这样指定。

| 参数 | 行为 |
| --- | --- |
| `count=6`、`count=10`、`count=14` | 启动时选择题数 |
| `seed=<数值>` | 固定题目选择和生成等用的随机数。不能固定全部视觉效果的随机数 |
| `extra=<秒>` | 替换加试默认的 90 秒。开始时加的 900 毫秒是共通的 |
| `skill=<技能ID>` | 用这个技能替换通常的题目选择。和复习、固定模板一起用时，选择处理有优先级 |
| `demo` | 从我的等级入口开始固定模板的基础组。第一题是 27＋35。不进行自动操作 |
| `capture` | 收集声音事件的确认路径。抑制通常的实时声音输出、自动引导和标题奖励通知等 |

`skill` 和固定模板的游玩会停止通常的答题时间、成长统计和任务，但完成历史和复习仍会保存。`skill` 下如果出题计划是实力检测，计划侧的掌握授予和检测完成的保存也会运行。奖杯判定在 `skill` 和 `capture` 下停止，但只指定 `demo` 不会停止。`capture` 下通常的进度、历史和统计保存仍会继续。不要把这些当成不留记录的练习功能。
